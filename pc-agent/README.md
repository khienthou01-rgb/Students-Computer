## 📌 សេចក្តីផ្តើម & លក្ខណៈពិសេសទាំង ១២

## 🚀 របៀបដំឡើងលើកុំព្យូទ័រសិស្ស (Step-by-Step Installation Guide)

> [!IMPORTANT]
> **ជំហានពិសេសសម្រាប់ម៉ាស៊ីនដែលមានដំឡើង Deep Freeze (ការពារ Windows):**  
> ប្រសិនបើកុំព្យូទ័រសិស្សមានប្រើ **Deep Freeze** សូមលោកគ្រូ **Unfreeze (Boot Thawed)** ជាមុនសិន៖  
> 1. ចុចគ្រាប់ចុច `Ctrl + Alt + Shift + F6` (ឬចុចពីរដងលើរូបខ្លាឃ្មុំ Deep Freeze នៅជ្រុងខាងស្តាំក្រោមជិតម៉ោង)
> 2. វាយលេខសម្ងាត់ (Password) របស់លោកគ្រូ
> 3. ជ្រើសរើសយក **Boot Thawed** រួចចុច **Apply and Reboot** ដើម្បី Restart កុំព្យូទ័រ។  
> *(បើសិនជាកុំព្យូទ័រធម្មតាគ្មាន Deep Freeze ទេ អាចរំលងចំណុចនេះបាន)*

---

### ជំហានទី ១៖ ចម្លង Folder `pc-agent` ទៅដាក់លើ PC សិស្ស
1. ដោត Flash Drive (USB) ដែលមានផ្ទុក Folder **`pc-agent`** នេះចូលទៅក្នុងកុំព្យូទ័រសិស្ស។
2. ចម្លង (Copy) Folder `pc-agent` ទាំងមូល ទៅដាក់ក្នុង Drive `C:\` នៃម៉ាស៊ីនសិស្ស៖
   * **ផ្លូវទីតាំងផ្លូវការ៖** `C:\pc-agent\`

---

### ជំហានទី ២៖ កំណត់លេខសម្គាល់ម៉ាស៊ីន (ធ្វើតែម្តងគត់)
1. បើកចូលទៅក្នុង Folder `C:\pc-agent\` លើម៉ាស៊ីនសិស្ស។
2. ចុចពីរដង (Double Click) លើឯកសារ **`Start-Agent.bat`**
3. ផ្ទាំងពណ៌ខៀវនឹងបង្ហាញឡើង ដោយសួរឱ្យលោកគ្រូវាយលេខសម្គាល់ម៉ាស៊ីន៖
   * បើកៅអីទី ១ វាយ៖ `PC-01` រួចចុច **Enter**
   * បើកៅអីទី ២ វាយ៖ `PC-02` រួចចុច **Enter**
   * *(កំណត់រហូតដល់ `PC-14` តាមលេខសម្គាល់កៅអីនីមួយៗ)*
4. ប្រព័ន្ធនឹងបង្កើតឯកសារ **`pc_id.txt`** ដើម្បីចងចាំលេខម៉ាស៊ីននេះជារៀងរហូត។
5. **ផ្ទៀងផ្ទាត់ភ្លាមៗ៖** សង្កេតមើលផ្ទាំងរបស់លោកគ្រូលើទំព័រ *«កាលវិភាគ & PC Lab»* លោកគ្រូនឹងឃើញកាត PC នោះលោតភ្លើងបៃតង **Online** និងចាប់ផ្តើមបញ្ជូនរូបភាពអេក្រង់មកភ្លាម!
6. ចុចបិទផ្ទាំងខ្មៅ CMD នោះវិញបាន។

---

### ជំហានទី ៣៖ កំណត់ឱ្យដំណើរការអូតូរាល់ពេលបើកកុំព្យូទ័រ (Auto-Start)
1. នៅក្នុង Folder `C:\pc-agent\` ដដែល សូមចុចពីរដង (Double Click) លើឯកសារ **`Install-AutoStart.bat`** តែម្តងគត់!
2. កម្មវិធីនឹងបង្កើតផ្លូវកាត់ (Shortcut) ទៅក្នុងថត `Windows Startup` ដោយស្វ័យប្រវត្តិ។
3. ផ្ទាំង CMD នឹងប្រាប់ថា៖ `[OK] បានដំឡើង Auto-Start ជោគជ័យ!`
4. ចុចគ្រាប់ចុចណាមួយដើម្បីបិទផ្ទាំងនេះ។

---

### ជំហានទី ៤៖ Freeze Deep Freeze ឡើងវិញ (បើមាន)

   *(សិស្សក៏អាចចុចលើប៊ូតុងប្តូរវេនបានដោយសេរី ករណីមកចូលរៀនខុសម៉ោងធម្មតា)*
3. **ជ្រើសរើសឈ្មោះសិស្ស (មិនបាច់មានលេខតុ ឬលេខកៅអីទេ)៖**
   * សិស្សគ្រាន់តែ **ចុចជ្រើសរើសឈ្មោះរបស់ខ្លួន** ពីក្នុងបញ្ជីឈ្មោះសិស្សដែលបង្ហាញលើអេក្រង់ (ឬវាយស្វែងរកឈ្មោះក្នុងប្រអប់ Search)។
   * ចុចលើប៊ូតុង **«🚀 ចូលរៀន & កត់ត្រាវត្តមាន (Sign-In)»**។
4. **កត់ត្រាវត្តមានភ្លាមៗជាស្វ័យប្រវត្តិ៖**
   - **វត្តមាន (Present) ត្រូវកត់ត្រាភ្លាម៖** ប្រព័ន្ធនឹងបញ្ជូនទិន្នន័យទៅកាន់ Database ហើយស្រង់វត្តមានសិស្សនោះជា **«វត្តមាន»** ក្នុងវេនដែលសិស្សកំពុងរៀនភ្លាមៗដោយស្វ័យប្រវត្តិ។
   - **លើផ្ទាំងរបស់លោកគ្រូ៖** ឈ្មោះសិស្សនឹងត្រូវភ្ជាប់ជាមួយកាត PC នោះភ្លាមជាមួយផ្លាក `✅ វត្តមាន (Sign-In)` ហើយក្នុងតារាងវត្តមានប្រចាំថ្ងៃរបស់គ្រូក៏លោតពណ៌បៃតងភ្លាមដែរ!
   - ផ្ទាំងធំនឹងបង្រួមខ្លួនទៅជា **បន្ទះជំនួយការតូចមួយ (Floating Toolbar)** យ៉ាងស្រស់ស្អាតនៅជ្រុងខាងស្តាំខាងលើនៃអេក្រង់កុំព្យូទ័រសិស្ស (ឧ. `[ព្រឹក] ចាន់ សុខា` ដោយមិនមានលេខតុរញ៉េរញ៉ៃឡើយ)។

### ២. ពេលសិស្សមានចម្ងល់ ឬលំហាត់ធ្វើមិនចេញ (🙋‍♂️ លើកដៃសួរគ្រូ)
- សិស្សគ្រាន់តែចុចលើប៊ូតុង **«🙋‍♂️ លើកដៃសួរគ្រូ»** នៅលើបន្ទះតូចជ្រុងស្តាំលើ។
- ប៊ូតុងនោះនឹងប្រែជាពណ៌ក្រហមភ្លឹបភ្លែត `🤚 កំពុងលើកដៃ...`។
- លើផ្ទាំងបញ្ជារបស់លោកគ្រូ នឹងមានសំឡេងបន្លឺឡើង និងលោតផ្ទាំងក្រហមព្រមាន `PC-XX: [ឈ្មោះសិស្ស] កំពុងលើកដៃសួរ!`។ លោកគ្រូអាចដើរទៅជួយសិស្សចំគោលដៅភ្លាមៗ។
- ពេលលោកគ្រូពន្យល់ចប់ គ្រាន់តែចុចលើ Badge លើកដៃលើផ្ទាំងគ្រូ ឬសិស្សចុចលើប៊ូតុងនោះម្តងទៀតដើម្បីបិទ។

### ៣. ជំនួយការគ្រាប់ចុចកាត់ (⌨️ Shortcut Keys Reference)
- ពេលសិស្សភ្លេចគ្រាប់ចុចកាត់ អាចចុចលើប៊ូតុង **«⌨️ Shortcut Keys»**។
- ផ្ទាំង Cheat-sheet នឹងបង្ហាញភ្លាមនូវគ្រាប់ចុចកាត់ចាំបាច់សម្រាប់កុំព្យូទ័ររដ្ឋបាល៖
  * របៀបវាយជើងអក្សរខ្មែរ (`F` / `J` + អក្សរ)
  * ប្តូរភាសាខ្មែរ/អង់គ្លេស (`Alt + Shift`)
  * អក្សរដិត ទ្រេត គូសបន្ទាត់ក្រោម (`Ctrl + B`, `Ctrl + I`, `Ctrl + U`)
  * រូបមន្ត Excel ជាប់ ($) (`F4`)
  * ចុះទំព័រថ្មី Word (`Ctrl + Enter`)
  * Save ឯកសារ (`Ctrl + S`)

### ៤. មុខងារការពារដាច់ភ្លើង (⚡ Auto-Save Recovery Guard)
- ប្រព័ន្ធ Agent នឹងធ្វើការស្កេន និង Copy រាល់ឯកសារ Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`) ដែលសិស្សកំពុងអនុវត្តនៅលើ Desktop រៀងរាល់ **៣០ វិនាទីម្តង** ទៅរក្សាទុកក្នុងថត `C:\tis-agent\Backup\AutoSave\` ដោយស្វ័យប្រវត្តិ។
- ប្រសិនបើមានបញ្ហាដាច់ភ្លើង ឬម៉ាស៊ីនគាំង សិស្សគ្រាន់តែបើកថតខាងលើឡើងមក នោះនឹងឃើញឯកសារចុងក្រោយដែលបាន Save ជានិច្ច មិនបារម្ភរឿងបាត់ការងារឡើយ!

## 🛠️ របៀបដោះស្រាយបញ្ហា និងសំណួរញឹកញាប់ (Troubleshooting & FAQs)

### ១. តើកុំព្យូទ័រសិស្សត្រូវការដំឡើងកម្មវិធីអ្វីបន្ថែមទេ?

### ២. ហេតុអ្វីកុំព្យូទ័រសិស្សមិនបង្ហាញ Online លើផ្ទាំងរបស់លោកគ្រូ?

* **ពិនិត្យលេខសម្គាល់ PC៖** បើកមើលឯកសារ `pc_id.txt` ថាតើបានសរសេរត្រូវទម្រង់ដែរឬទេ (ឧ. `PC-01`, `PC-02` មិនត្រូវមានដកឃ្លាឡើយ)។

### ៤. តើធ្វើដូចម្តេចទើបដឹងថា Agent កំពុងដំណើរការក្នុង Background?
